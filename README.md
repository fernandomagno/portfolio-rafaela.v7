# Rafaela Benatti — Editorial

Versão editorial de moda infantil para o ensaio de desfile, com direção visual inspirada em revistas de moda e identidade própria.

## Abrir

Abra `index.html` no navegador ou publique a pasta no GitHub Pages. As 20 fotos do desfile ficam na raiz da pasta `v7.2`.

## Recursos

- Capa editorial responsiva.
- Galeria com composição de revista.
- Lightbox para ampliar fotos.
- Fotos coloridas do desfile.
- Navegação fixa e links de contato.
- Animações suaves de entrada.
